# GoTogether – Activity Companion Platform

GoTogether is a React-based application that helps users discover,
create, search, and manage activities with people who share similar
interests.

## Live Demo

https://go-together-react.vercel.app

## Features

- User registration and login
- Explore and search activities
- Filter activities by location, date, and category
- Create, edit, and delete activities
- View activity details
- Add and remove favorite activities
- Responsive design for mobile and desktop

## Technologies Used

- React.js
- JavaScript
- React Hooks
- Redux Toolkit
- React Router
- HTML
- CSS
- LocalStorage
- Vite

## Run Locally

1. Clone the repository:

   git clone https://github.com/rahaman109/GoTogether-react.git

2. Open the project folder:

   cd GoTogether-react

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev

5. Open the local URL shown in your terminal.
